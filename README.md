# React-Mini-Project

A mini web project built with React and Vite.

## About

This project was created as a practical React project to learn and practice the fundamentals of modern React development.

The project uses Vite as the development and build tool and follows a standard React project structure.

## Technologies

- React
- JavaScript
- Vite
- HTML5
- CSS3
- ESLint

## Installation

Clone the repository:

```bash
git clone https://github.com/samanyarzada/React-Mini-Project.git
```

Navigate to the project folder:

```bash
cd React-Mini-Project
```

Install the dependencies:

```bash
npm install
```

## Run the Project

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

## Build

To create a production build:

```bash
npm run build
```
